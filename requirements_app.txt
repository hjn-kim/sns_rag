# 메신저 RAG - 데모 앱 공통 의존성 (환경 무관)
#
# 이 파일만 단독으로 쓰지 말고, 환경에 맞는 쪽을 설치한다:
#
#     로컬 PC (GPU 없음)   pip install -r requirements_local.txt
#     RunPod 등 GPU 팟     pip install -r requirements_runpod.txt
#
# 둘 다 이 파일을 -r 로 끌어다 쓴다. 여기에는 torch 를 넣지 않았다.
# torch 는 환경마다 받아야 할 빌드가 달라서(CPU 휠 / CUDA 휠) 각 파일이 따로 다룬다.
#
# 실행:
#     streamlit run app.py
#     python src/main.py --lang ko "질문"        # 터미널에서 파이프라인만
#
# .env 에 GEMINI_API_KEY 가 있어야 한다. .gitignore 로 제외돼 있으니 새 환경에서는
# clone 후 직접 만든다.
#     GEMINI_API_KEY=your-key-here
#
# 임베딩 모델(약 1.2GB)은 첫 검색 때 자동으로 받는다. ~/.cache/huggingface 에 남는다.

# --- 화면 (app.py) ---------------------------------------------------------

# google-genai 는 라이브 세션용으로 websockets 를 import 하는데, 허용 범위가
# 좁다(>=13,<15.1). 범위 밖 버전이 섞이면 genai 를 import 하는 것만으로 죽는다:
#     ImportError: cannot import name 'BytesLike' from 'websockets.typing'
# 다른 패키지(langsmith 는 >=15.0, langgraph-sdk 는 >=14,<16 ...)가 끌어올려
# 어긋나는 일이 실제로 있었다. 그래서 여기서 못 박는다.
websockets>=13.0,<15.1
