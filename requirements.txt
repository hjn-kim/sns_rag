#   src/cpu_translator.py   Google 무료 API (deep-translator). GPU 불필요
#   src/gpu_translator.py   NLLB-200 로컬 추론 (torch/transformers)
#
# ==========================================================================
# torch 는 일부러 넣지 않았다. pip 에게 맡기면 GPU 환경이 깨진다
# ==========================================================================
#
#   pip 가 PyPI 기본 torch 휠을 깔면 드라이버보다 새 CUDA 로 빌드된 것이 올 수 있다.
#   그러면 GPU 를 아예 못 잡고 조용히 CPU 로 떨어진다:
#     CUDA initialization: The NVIDIA driver on your system is too old (found version 12080)
#     장치  : cpu / float32
#   (12080 = 드라이버가 지원하는 CUDA 12.8. 그보다 새 빌드는 못 돌린다)
#
#   그래서 torch 는 드라이버에 맞춰 직접 깐다. 드라이버 확인:
#     nvidia-smi | head -3          # CUDA Version 을 본다
#   그 버전에 맞는 인덱스에서 설치 (12.8 이면 cu128, 12.4 면 cu124 ...):
#     pip install torch --index-url https://download.pytorch.org/whl/cu128
#   확인 - 세 번째 값이 True 여야 한다:
#     python -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available())"
#
#   transformers 5.x 는 torch.distributed.tensor 를 쓰므로 torch 2.5 이상이어야 한다.
#   더 낮은 torch 를 써야 하면 DTensor ImportError 가 나므로 'transformers<5' 로 낮춘다.
#
#   torch 를 바꾸면 팟에 딸려 있던 torchvision/torchaudio 는 옛 torch 로 빌드된 채
#   남아 어긋난다. 그 상태로 모델을 올리면 이렇게 터진다:
#     RuntimeError: operator torchvision::nms does not exist
#     ModuleNotFoundError: Could not import module 'M2M100ForConditionalGeneration'
#   번역에는 둘 다 안 쓰이고 transformers 는 없으면 건너뛴다. 지우는 게 제일 간단하다:
#     pip uninstall -y torchvision torchaudio
#   팟의 다른 작업 때문에 남겨야 하면 torch 와 같은 인덱스에서 다시 깐다:
#     pip install --force-reinstall torchvision --index-url https://download.pytorch.org/whl/cu128
#
# --------------------------------------------------------------------------
# torch 를 확인한 뒤:  pip install -r requirements.txt
# --------------------------------------------------------------------------

# --- gpu_translator.py / embedding.py ------------------------------------
# torch 2.4 팟에서는 transformers 를 4.51.x 로 고정해야 한다. 위아래로 다 막힌다.
#
#   4.51 미만  임베딩 모델(microsoft/harrier-oss-v1-0.6b)이 Qwen3 인데
#              qwen3 지원이 4.51.0 에 처음 들어갔다. 4.50 에는 아키텍처가 없다.
#   4.52 이상  CVE-2025-32434 때문에 torch 2.6 미만에서 .bin 체크포인트 로딩을
#              막는다. NLLB 공식 저장소는 전부 pytorch_model.bin 뿐이라 걸린다:
#                ValueError: ... require users to upgrade torch to at least v2.6
#   5.x       torch.distributed.tensor 의 DTensor 를 쓰는데 그 경로는 torch 2.5
#              부터 생겼다: ImportError: cannot import name 'DTensor'
#
# torch 를 2.6 이상으로 올리면 이 제약이 다 풀리지만, 드라이버보다 새 CUDA 빌드가
# 들어오면 GPU 를 통째로 잃는다. torch 를 고정하고 transformers 를 맞추는 쪽이 안전하다.
transformers>=4.51,<4.52
tqdm>=4.66
